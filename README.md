# Azure & PMI DevOps Integration Labs

This repository contains practical code samples, Terraform modules, and Python automation scripts designed to align Microsoft Azure cloud deployment with PMI (Project Management Institute) agile and waterfall governance models.

## 📌 Repository Structure

* `azure-infrastructure/`: Infrastructure as Code (IaC) templates for automated provisioning on Azure.
* `project-governance/`: Python scripts for task tracking, API integrations, and workflow automation.

## 🚀 Quick Start

### Prerequisites
* Azure CLI installed
* Terraform v1.5.0+
* Python 3.10+

### Usage Example (Terraform)
```bash
cd azure-infrastructure
terraform init
terraform plan
