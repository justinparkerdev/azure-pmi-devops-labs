Automated Terraform scripts, project governance workflows, and certification practice labs for Microsoft Azure & Enterprise PMI frameworks.

## 📁 Repository Structure
- `azure-infrastructure/`: Infrastructure as Code (IaC) Terraform modules.
- `project-governance/`: Automation scripts and PMI project workflow templates.
- `docs/`: Technical guides, architecture design records, and prep resources.
